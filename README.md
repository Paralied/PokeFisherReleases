# Poke Auto Fisher

Made by Paralied.

[Download the latest Windows EXE](https://github.com/Paralied/PokeFisherReleases/releases/latest/download/PokeAutoFisher.exe)

Press **F6** to arm or disarm, then cast once. Enable **Auto Cast** to continue fishing after each catch. Press **End** to exit. Keep Roblox in the foreground.

Version 1.15 adds in-app update checks, broader water detection for different graphics settings, and remembers a successful manual cast location during the session. Failed casts are retried.

Future updates appear in the app: choose **Install** to download and restart. The updater verifies the download checksum and retains the previous executable.

This repository contains compiled releases only.
